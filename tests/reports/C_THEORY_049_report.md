## C3: rungs 2–3 register tells (Should) — done

**Cause.** Rungs 2–3 drew a target lowest/highest note and took the nearest of 20 (rung 2) or 9 (rung 3) grid realisations. Each model's
realisations sit on a few exact pitches, so the exact lowest+highest pair still named the answer. Rung 2 also used only 7 major / 5 minor

**Change (index.html).**
- Rungs 2–3 now work like rung 1. `earR23Index` lists every (mode, answer, model, key, grid point) in a fixed order; `earR23Pool` realises
  each with the same strict code the questions use (`earCadProg`, memoised in `earCadM`); `earR23Fit` (deterministic iterative proportional
  fitting) weights them so that, within each mode, every answer has the same distribution of key, opening voicing, first bass, first soprano,
  lowest note, highest note, the exact pair, span, last bass and last soprano. Each answer keeps exactly its old model share (a length, then
  a model of that length), so length / mode / second-chord balance is unchanged. A 10 % mix with the plain prior keeps variety (≥ 100 distinct
  items per rung 3 answer).
- The pool takes ~65 s in Chrome, so the weights are stored in `const EAR23W` (3 base-36 chars per entry, 48.6 KB) and regenerated by the new
  `tests/gen_cad23_weights.py`. If the table is missing or its length does not match the index, the old draw is used (and earlab_test fails).
- Rung 2 cadences use all 24 keys (`earCadKeys`; `CKEYS2` itself is unchanged and still drives melodic dictation). This is what removes the
  absolute last-bass tell (IC_EAR2_048 C2 names it). **Flag for Justin:** a behaviour change beyond registers; easy to revert if the 7/5 key
  set was a deliberate Stage 5 choice (the last-bass tell then returns, about +7 to +17 points).
- Rung 3 grid widened from 3×3 to 5×5 (bass 41–53, soprano 64–76, same outer bounds), which gave the fit enough freedom (with 3×3 the last
  soprano stayed at +5–6). Every new grid realisation is strict (below).
- Questions are faster: one realisation per question instead of all grid points (mean 63 ms vs 380 ms at rung 2, 25 vs 96 ms at rung 3).
- `EARCADM` memo key now includes the rung (the opening voicing depends on it; no current collision, latent only).

## C8: symmetrical sentences (Should) — done

The Chord Library texts said the augmented triad is "symmetrical" and the dim7 "divides the octave into four equal parts" and is "the
leading-note 7th of four different keys". Strictly: the symmetry holds only in equal temperament (the wrap-round interval is a diminished
4th / augmented 2nd, enharmonic with the major / minor 3rd), and a dim7 is vii°7 of four *minor* keys (a minor 3rd apart). New texts say
exactly that ("On a piano (equal temperament) it is symmetrical: from the top note up to the root again is a diminished 4th, which sounds the
same as a major 3rd, so ... every inversion sounds like another augmented triad in root position"; the dim7 likewise, "the leading-note 7th
(vii°7) of four different minor keys a minor 3rd apart"). The unused Ear Lab `QSYM` strings ("each note is a major 3rd above the last") were
corrected the same way. unit_test C8 checks the key phrases. An independent content check is still due (register: "content check by
independent checker").
